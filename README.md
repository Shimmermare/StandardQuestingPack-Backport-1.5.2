Standard Expansion Unofficial 1.5.2 port
============

An unofficial port of Standard Expansion for BetterQuesting 3 from 1.7.10 to 1.5.2 made for [CakeHiTech Memories](https://github.com/Shimmermare/CakeHiTechMemories) modpack.

Contains all the basic tasks, rewards, importers and themes for the Better Questing mod

## Comparison to 1.7.10 original

### Unavailable features
- Mod configuration hot reload and editing in GUI.
- Removed importers from FTB Quests and HQM (obviously).
